## 1. Arsitektur Navigasi & *Routing* Saat Ini

Secara arsitektural, aplikasi *frontend* RoadPriority (`React 19.3.1` + `Vite 8.3.5` + `Leaflet 1.9.4`) merupakan **Single-View State-Driven SPA** tanpa pustaka *client-side router* (`react-router-dom` tidak terpasang pada [`frontend/package.json`](file:///c:/Users/MyBook%20Hype%20AMD/OneDrive/Documents/ML/RoadPriority/frontend/package.json)):

- **URL Tunggal:** Seluruh tampilan diakses melalui satu *path* `http://127.0.0.1:5173/` (atau `:5174` pada *server* pengujian).
- **Pengendali Tampilan Utama:** State React `activeTab` di dalam [`HomePage.jsx`](file:///c:/Users/MyBook%20Hype%20AMD/OneDrive/Documents/ML/RoadPriority/frontend/src/pages/HomePage.jsx#L31) mengatur perpindahan antar-modul (`public`, `create`, `my-reports`, `officer`, `decision-engine`).
- **Pengendali Sub-Modul SPK:** State React `subTab` di dalam [`DecisionEnginePanel.jsx`](file:///c:/Users/MyBook%20Hype%20AMD/OneDrive/Documents/ML/RoadPriority/frontend/src/components/DecisionEnginePanel.jsx#L19) mengatur perpindahan antar-tahap di dalam modul `Prioritas AHP-TOPSIS` (`criteria_readiness`, `ahp_weights`, `topsis_runs`, `run_verification`).
- **Pengendali Detail & Verifikasi:** State React `selectedReportId` di dalam [`HomePage.jsx`](file:///c:/Users/MyBook%20Hype%20AMD/OneDrive/Documents/ML/RoadPriority/frontend/src/pages/HomePage.jsx#L47) menampilkan komponen *overlay* [`ReportDetailModal.jsx`](file:///c:/Users/MyBook%20Hype%20AMD/OneDrive/Documents/ML/RoadPriority/frontend/src/components/ReportDetailModal.jsx).

## 5. Kesenjangan Cakupan *Backend* terhadap *Frontend* (*Backend-to-Frontend Feature Gap*)

Berdasarkan audit silang antara [`backend/routes/api.php`](file:///c:/Users/MyBook%20Hype%20AMD/OneDrive/Documents/ML/RoadPriority/backend/routes/api.php) dan seluruh komponen di `frontend/src/`, terdapat **6 kapabilitas backend yang sudah berfungsi dan teruji otomatis**, tetapi **belum memiliki antarmuka pengguna (UI) di frontend**:

| No | Endpoint / Kapabilitas Backend | Otorisasi Backend | Status di Service Frontend | Status di Komponen UI | Dampak bagi Pengguna |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **1** | **Registrasi Mandiri Akun Warga** (`POST /api/auth/register`) | Publik (`throttle:10,1`) | Sudah ada di [`reportingService.js#L13`](file:///c:/Users/MyBook%20Hype%20AMD/OneDrive/Documents/ML/RoadPriority/frontend/src/services/reportingService.js#L13) (`registerAccount`) | **Belum ada di UI** (Header hanya menampilkan form Login & tombol akun demo) | Warga baru tidak dapat mendaftarkan akun sendiri melalui antarmuka web. |
| **2** | **Manajemen Pengguna & Status Aktif/Nonaktif** (`GET /api/users`, `POST /api/users`, `GET /api/users/{id}`, `PATCH /api/users/{id}`) | `permission:users.manage` (`admin`) | Belum ada di `src/services/` | **Belum ada di UI** | Admin tidak dapat menambah petugas baru, mengubah *role*, atau menonaktifkan akun dari browser. |
| **3** | **Peninjauan Audit Log Keamanan & Operasional** (`GET /api/audit-logs`) | `permission:audit-logs.view` (`admin`, `kepala_dinas`) | Belum ada di `src/services/` | **Belum ada di UI** | Jejak audit (`ahp.weight_version.activated`, `decision.run.executed`, `report.verified`, `road_segments.geojson_imported`) hanya bisa diperiksa lewat database atau API manual. |
| **4** | **Penambahan / Pembaruan Kriteria Keputusan** (`POST /api/criteria`, `PATCH /api/criteria/{id}`) | `permission:criteria.manage` (`admin`) | Belum ada di `decisionService.js` (hanya `fetchCriteria`) | **Belum ada di UI** (`DecisionEnginePanel.jsx` hanya merender tabel baca-saja) | Admin tidak dapat mengubah nama, satuan, atau status aktif kriteria melalui UI. |
| **5** | **Manajemen Master Ruas Jalan & Riwayat Asesmen per Segmen** (`POST /api/road-segments`, `PATCH /api/road-segments/{id}`, `GET /api/road-segments/{id}/assessments`) | `permission:road-segments.manage` & `assessments.view` | `createRoadSegment` & `updateRoadSegment` sudah ada di [`reportingService.js#L64-L74`](file:///c:/Users/MyBook%20Hype%20AMD/OneDrive/Documents/ML/RoadPriority/frontend/src/services/reportingService.js#L64-L74) | **Belum ada di UI** | Petugas/Admin hanya dapat mengisi asesmen baru di Sub-tab 1 SPK, tetapi tidak dapat melihat riwayat lengkap asesmen per segmen atau memperbarui atribut master ruas jalan dari UI. |
| **6** | **Impor & Dry-Run GeoJSON Ruas Jalan** (`php artisan roadpriority:import-segments`) | CLI Artisan | Tidak ada endpoint HTTP unggah file GeoJSON | **Hanya CLI** | Admin harus menjalankan perintah terminal untuk melakukan *dry-run* atau mengimpor GeoJSON ruas jalan resmi. |
